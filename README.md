# ⚡ LeetCode 每日刷题助手

根据你 LeetCode 个人主页公开的**题单**，自动生成每日刷题计划（新题 + 复习），内置**记忆库**、**月历排布**、**专注计时器**与 **WebDAV 多端同步**。跨平台（Linux / Windows 11 / macOS）。

## ✨ 功能总览

| 需求 | 实现 |
|---|---|
| 按月排布、中等难度为主 | 月份计划可配置（9/10/11 月内置冲刺预设，其余月份日常预设），新题优先选 MEDIUM，不足回退 简单/困难 |
| 9 月：新 2 + 复习 3 | ✅ 内置预设（可改） |
| 10 月：新 1~2 + 复习 3~4 | ✅ 内置预设（区间内每天随机取值） |
| 11 月：以复习为主 | ✅ 内置预设：新 0~1 + 复习 3~5 |
| 标注新题/复习来源 | 每道题带「新题 / 复习」徽标 + 来源题单名 |
| 标注题目类别 | LeetCode 官方类别标签（二叉树、网格图、动态规划…） |
| 记忆功能 + 每日抓取 | 按题号去重记忆「首次出现/排期/完成/上次复习」；每天定时抓取题单并自动对账，同一题出现在多个题单自动归入**复习**，杜绝“表面新题、实际旧题” |
| 点击题号一键跳转 | 系统浏览器打开 `leetcode.cn/problems/{titleSlug}/` |
| 人工更新刷题状态 | 未开始 / 进行中 / 已完成，一键全完成、全重置，可设休息日 |
| 专注计时器 | 倒计时圆环、提示音 + 系统通知、自动记录到统计 |
| 跨平台数据同步 | 内置 WebDAV 客户端（兼容坚果云），自动拉取/推送题单缓存、记忆库、计划与计时记录 |

## 🚀 快速开始

环境要求：**Node.js 18+**（https://nodejs.org）

```bash
# Linux / macOS
./scripts/start-linux.sh
# 或
npm start

# Windows
scripts\start-win.bat
# 或
npm start
```

首次启动会自动安装依赖（Electron 较大，请耐心等待）。

### 打包成安装包（可选）

```bash
npm run dist:linux   # Linux → dist/*.AppImage
npm run dist:win     # Windows → dist/*-Setup.exe（需在 Windows 上执行）
npm run dist         # 当前平台
```

## 🗓️ 使用流程

1. **题单管理**：填入你的 LeetCode 主页链接（默认 `https://leetcode.cn/u/kevinwu-z/`，在「设置」中修改），点「保存并抓取题单」。工具会读取主页「题单」Tab 下的全部公开题单并缓存题目（含难度、类别标签）。可单独停用某些题单。
2. **今日计划**：只有**当天**的题单会被生成、并允许修改刷题状态。其他日期（过去 = 刷题记录、未来 = 预览）一律**只读**；早于「计划开始日期」（默认 2026-09-01，可在设置修改）的日子不生成题单。新题按**知识点轮转**选取（保证各题单类别雨露均沾），复习题按**间隔重复**排序（越久没复习越优先）。点题号跳转做题，做完点「已完成」。
3. **月历排布**：查看整月排布（灰色=休息日），点击任意日期查看/修改，右上角可切换休息状态。
4. **记忆库**：按题号去重的全局记忆。可「标记掌握」（不再排）、「标记已做过」（加入工具前刷过，今后按复习处理）、「删除」。
5. **专注计时**：设定时长开始专注，完成自动记录（统计页可见）。
6. **设置**：月份节奏（新题/复习数量、休息日）、抓取时间、同步配置、数据目录、导出/导入备份。

## ☁️ 多端同步（WebDAV / 坚果云）

1. 注册/登录坚果云（https://www.jianguoyun.com），在「账户信息 → 安全选项 → 添加应用密码」生成**应用专用密码**。
2. 打开「设置 → 数据同步」，填写：
   - 服务器地址：`https://dav.jianguoyun.com/dav`
   - 用户名：坚果云登录邮箱
   - 密码：刚生成的应用密码（非登录密码）
   - 远程目录：`/LeetCodeDailyHelper`（多台设备保持一致即可互通）
3. 点「测试连接」→「保存同步设置」→「立即同步」。

之后每次数据变化自动推送、启动时与每 30 分钟（可配置）自动双向同步。两台电脑使用相同配置即可互相同步：题单缓存、记忆库、每日计划、计时记录。

> 提示：`config.json` 也在同步范围内，换机后无需重复配置。若不想同步某些文件，可把该文件从 `远程目录` 中删除后重新同步。

## 🧠 记忆与去重机制

- 记忆库以 **LeetCode 题号**（questionFrontendId）为主键，跨题单去重。
- 「新题」= 从未被本工具排期过的题；「复习」= 已排期/已完成的题。
- 同一道题后来被加入新题单、或同时存在于多个题单时，自动识别为**旧题**进入复习队列，不会重复计为新题。
- 每次抓取自动更新题目标题/标签信息与所属题单列表。

## 💾 数据文件（均为 JSON，便于备份与同步）

| 文件 | 内容 |
|---|---|
| `config.json` | 用户主页、月份计划、抓取/同步/计时配置 |
| `lists.json` | 题单缓存（含题目、难度、标签） |
| `history.json` | 记忆库（去重、排期/完成统计） |
| `plan.json` | 每日计划与状态 |
| `sessions.json` | 专注计时记录 |
| `syncState.json` | 同步状态（各文件 mtime） |

默认数据目录：Linux `~/.config/LeetCode每日刷题助手/data`（实际为 Electron userData/data）；可在「设置 → 数据管理」中修改，修改时会自动迁移已有数据。也可放到 OneDrive/坚果云同步盘目录实现系统级同步。

## 🔧 数据来源说明

通过 LeetCode 中国站公开 GraphQL 接口获取（无需登录）：

- `userProfilePublicProfile` — 用户公开资料
- `createdPublicFavoriteList` — 用户公开题单列表
- `favoriteQuestionList` — 题单内题目（含难度、标签）

## ⚠️ 常见问题

- **抓取失败 / 限流**：LeetCode 对高频请求有限制，程序已带重试；建议保持默认的每天一次自动抓取，不要频繁手动刷新。
- **启动时提示数据目录**：数据目录可随时在设置中更换。
- **Linux 下打开报缺少依赖**：安装 `libnss3 libatk-bridge2.0-0 libgtk-3-0 libgbm1` 等常见 Electron 运行库（`sudo apt install libnss3 libatk-bridge2.0-0 libgtk-3-0 libgbm1`）。
- **Windows 智能屏幕提示**：源码运行（`npm start`）属于开发模式，属正常现象；打包后的安装包可正常安装。

## 📄 项目结构

```
main/           Electron 主进程（抓取、排期、同步、IPC、定时任务）
  leetcode.js   LeetCode GraphQL 抓取
  scheduler.js  记忆库 + 每日计划生成
  sync.js       WebDAV 同步
  store.js      JSON 持久化
renderer/       界面（今日计划 / 月历 / 题单 / 记忆库 / 统计 / 计时 / 设置）
scripts/        启动脚本 + 冒烟测试
```
